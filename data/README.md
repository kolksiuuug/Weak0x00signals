# Данные проекта

Для финального обучения положительные примеры берутся из **официального XLSX заказчика**. Проект ожидает файл `official_dataset.xlsx` (лист `Слабые сигналы`) в этой директории либо путь через `OFFICIAL_DATASET_PATH`.

Негативные кандидаты должны быть собраны командой отдельно и сохранены в `negative_candidates.csv`. Это не место для выдуманных меток: каждая строка должна быть проверяемым зрелым/хайповым/шумовым кандидатом с основанием в источниках.

В текущем ZIP официального XLSX нет, поэтому репозиторий не содержит поддельных 100 строк и не заявляет финальные P/R/F1.
